# football-data-analysis-web-scraping
Web scraping y análisis de la selección española de fútbol mediante Python, Pandas y diferentes visualizaciones de datos.

# Funcionamiento Del Programa
Text Mining y Web Scraping de la Selección Española Este proyecto consiste en aplicar técnicas de web scraping, limpieza, análisis y visualización de datos sobre la convocatoria de la selección española de fútbol. Los datos se obtienen de Transfermarkt, utilizando `Requests` para realizar la petición HTTP y `BeautifulSoup` para extraer la información de la tabla de jugadores. Una vez obtenidos los datos, se crea un `DataFrame` con `Pandas` que contiene información como el nombre, posición, edad, club y valor de mercado de cada jugador. Antes de realizar el análisis, se limpian los datos extraídos de la web y se convierten los valores de edad y mercado en formatos numéricos para poder trabajar con ellos. El análisis se divide en diferentes partes. Primero se estudia la distribución de jugadores según su posición y se calcula el valor total y medio de cada grupo. Después se analizan los jugadores según su valor de mercado, identificando los más y menos valorados y estudiando la distribución de estos valores. También se representa la relación entre la edad y el valor de mercado mediante un gráfico de dispersión. Además, se analiza la procedencia de los jugadores mediante sus clubes. Para ello se utilizan gráficos de tipo donut y mapas de calor que permiten observar cómo se distribuye el valor de mercado entre clubes y posiciones. También se utiliza `NetworkX` para crear un gráfico que represente el peso de cada club dentro de la convocatoria según el número de jugadores que aporta. Finalmente, los datos procesados ​​se exportan a formatos CSV y JSON, permitiendo reutilizarlos posteriormente en otras herramientas o proyectos de análisis de datos.
